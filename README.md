# Cybersecurity-Game
Welcome to CyberQuest: Defenders of the Digital Realm!

This is an interactive, web-based game that teaches players about cybersecurity. It is intended for users of all demographics and is very beginner-friendly! Play the main game to complete simulated missions, and try the arcade mode, "Malware Mayhem", to learn all about malware types.

To Play: Click file's hyperlink > Click three horizontal dots at top right (More file actions) > Select "Download" 
Once you open the html file, it should then appear in your browser ready for you to play.
